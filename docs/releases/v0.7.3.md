# Agentic-Island v0.7.3

截图体验与图片美化升级版：入口分流更明确，美化能力扩展到画框、背景、画幅、标题和倒影，并保证按原图像素合成。

## 截图入口

- 岛内截图按钮与 `Ctrl+Alt+S` 进入「截图 → 美化工坊」，框选后 Enter 直接进工坊。
- 托盘「截图问答」保持截图后进入截图问答。
- 框选叠层出现前先隐藏岛，取消/完成后恢复，避免岛挡住选区。

## 图片美化

- 画框扩到 12 种：原图、玻璃拟态、macOS、浏览器、Windows 窗口、终端、极简、渐变描边、霓虹、暗夜、网格纸、拍立得。
- 背景：渐变、纯色（自定义取色）、原图放大虚化、透明。
- 画幅：原始、1:1、4:3、16:9、3:4、4:5、9:16。
- 标题/副标题：浅色底自动转深色文字，可自定义文字颜色。
- 桌面倒影：0–100% 可调。
- 内边距 0 = 真正无边框；玻璃画框实测 `1280×820 → 输出 1280×820`。

## 清晰度

- 采集走原生像素链路（审计实测 2560×1600）。
- 合成始终按原图分辨率；1x 原像素导出，2x/3x 仅放大画布并在界面明确标注。
- 预览缩放不影响导出；默认 PNG，不额外重采样。

## 验证

- 类型检查、52 个离线测试、生产构建通过。
- 11 分区扫页、对比度（硬失败 0）、问答、终端、验收台、截图工坊、真实录屏导出全部通过。
- 安装版审批闭环：岛上点「允许」后 hook 收到 `behavior=allow`。
