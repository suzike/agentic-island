# Agentic-Island v0.8.4

终端历史支持按会话分组批量删除，并修掉历史被终端协议序列污染的问题。

## 新增

- **历史分组批量删除**：终端 › 命令工具 › 历史新增「管理」模式。
  - 按会话分组：每组显示会话名与条数，提供「全选本组 / 删除本组」。
  - 跨组多选：点击整行勾选，底部显示「已选 N / M」，支持「全选筛选结果 / 取消选择 / 删除」。
  - 所有删除都走行内二次确认（`删除选中的 N 条历史？`），不会误点即删。
  - 只清理命令历史，不关闭终端会话、不清空输出、不影响正在运行的命令；删除结果随工作区落盘。
- **分组/删除纯逻辑**：`groupTerminalHistory` / `dropTerminalHistory`，按会话聚合、最近会话在前、组内最新在前。

## 修复

- **历史里的脏记录**：鼠标上报（`ESC[<…M`）、焦点上报（`ESC[I`）、括号粘贴标记、OSC 标题、SS3 功能键等终端协议序列此前只丢弃 ESC，剩余字节被当成用户输入记进历史（例如 `[<35;8;30M你好`）。现在完整跳过这些序列，方向键/Home 等编辑键仍保持「清空当前输入缓冲」的原语义。
- **回归覆盖**：新增协议序列与分组删除断言；`npm run audit:terminal` 增加真实 Electron 端到端（管理态 → 选中 → 二次确认 → 计数减一且会话保留）。

## 验证

类型检查、53 个离线测试、生产构建、12 分区 + 编排浮层对比度（硬失败 0）、问答、终端、验收台、截图工坊与真实录屏导出审计全部通过。
