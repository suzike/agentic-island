# Agentic-Island v0.8.3

修复流水线节点的跳转指向。

## 修复

- **「来源」节点曾跳到「规则」分段**（那里没有来源信息）。现在按语义分流：
  - **来源** → 可视化编排的「事件来源」分组
  - **规则** → 可视化编排的「规则 / 回路」分组
  - **排队 / 执行** → 「进行中」分段
  - **回执 / 复查** → 「近况」分段
  - **拍板** → 「待拍板」分段
- 规则拓扑里的规则名与触发图标同样走上面的映射。

## 新增回归审计

`npm run audit:super`：隔离实例启动 → 逐个点击七个流水线节点 → 断言落点（浮层分组内容 / 分段选中态）。这类"点了跳错地方"的问题从此有自动化兜底。

## 验证

类型检查、53 个离线测试、生产构建、12 分区 + 编排浮层对比度（硬失败 0）、节点跳转审计全部通过。
