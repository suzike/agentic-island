# Agentic-Island v0.7.4

面板收起行为修复。只改交互判定，不改动鼠标穿透、渲染性能、截图或录屏链路。

## 修复

- 点「收起」时取消待执行的自动收起计时器，同步清掉强制展开/待处理引用，并抑制指针仍停在折叠条上时的 hover 重开。
- 鼠标点击按钮产生的焦点不再被当成键盘操作；只有输入框、文本域或可编辑区聚焦时，才维持面板不自动收起。
- 1.2 秒防误收起窗口命中后会按剩余时间继续计时，不再直接放弃自动收起。

## 验证

- 真实系统光标：面板内停留 3 秒不收起；移到面板外自动收回；重新展开后真实点击「收起」可正常收起。
- 类型检查、52 个离线测试、生产构建与全功能审计通过。
- 0.7.3 的截图入口、12 种画框、背景/画幅/标题/倒影与 1x 原像素导出保持不变。
