# Agentic-Island v0.7.0

这一版把原来的 Plan 空页升级为真正的**验收台**，并收口 Agent 状态、截图高清、录屏性能和页面误收起。

## 验收台

- Agent 会话结束时留档最后回复、计划原文、实际改动文件与验证记录。
- 按「计划 → 实际改动 → 未验证项」对照；只有真实测试/构建命令才算执行证据，不把“执行过”写成“通过”。
- 改动归属改为会话开始时的工作区基线，不再把用户未提交的改动算进 Agent 产出；会话期间有提交会明确提示“清单只覆盖工作区”。

## 媒体与交互

- **截图高清**：框选裁剪使用主进程记录的真实 `scaleFactor`；本机 `1707×1067 @1.5x` 显示器实测抓帧 `2560×1600`。
- **截图落盘自检**：快存后解码成品并回传真实宽高，工坊显示“原图 → 输出”尺寸；尺寸不符会告警。
- **截图历史**：框选、整屏、滚动长截图自动归档到独立目录，可回看最近 40 张缩略图、载入原图、定位文件；自动保留最近 120 张。
- **截图首击**：叠层增加 `snip-ready` 握手与主进程 80ms 光标命中兜底，面板刚出现时不再第一下点击穿透。
- **页面误收起**：点击会取消旧的 260ms 收起计时器，点击后 1.2 秒内禁止自动收起；长文“展开全部”从固定 320px 改为最高 70vh，真正能展开。
- **录屏卡顿**：默认原始画面直通编码器，录制期运镜/光晕改到导出期重建；审计实测 `25.58fps → 27.09fps`，导出 `1080×1920 · 30fps · H264` 自检通过。
- **采集真实统计**：录制条每 1.2 秒读取采集轨，显示实际 FPS、丢帧率、像素尺寸和编码器；低于目标 80% 明确告警。
- **后期能力**：点击强调运镜、双语字幕（同时间码双行，SRT/VTT）、导出后读回自检与打开文件夹/复制路径/分享文案。
- **Codex 旧会话**：rollout 等待态 3 分钟、普通态 15 分钟无新增即回收；没有 rollout 的 hook 卡片按 Codex 等待态 10 分钟兜底移除，运行态 60 分钟，审批中的请求永远保留。
- **语音输入误判**：微信/豆包/Windows 语音输入和岛自身录音不再触发会议；连续占用 20 秒才进入会议态。
- **待办信息密度**：近期日程默认折叠。
- **升级稳定性**：按版本标记只清理可重建的 Chromium GPU/代码缓存，避免跨版本启动 FATAL；用户配置、录屏、附件、终端现场和知识库不动。
