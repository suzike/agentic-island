# Agentic-Island v0.7.1

界面精修版：十一个分区统一了一轮视觉与交互细节，并修掉几处长期存在的显示缺陷。功能、数据结构与 0.7.0 保持一致。

## 界面

- **设置**：验收规则与门禁合并为「补充规则 / 受保护路径」两张卡片，用全局/项目分段切换；审批策略统一成开关行 + 规则卡；规则输入改为通栏轻质字段。
- **问答**：多模型候选收成标签行，右侧只留「采用」；候选与气泡分析改为轻卡片；可继续追问整行可点；回答方法行去掉冗余说明。
- **待办**：AI 执行指挥条改为发丝线分段。
- **资讯**：TOP3 方形编号，审稿流水线改为细进度条。
- **复盘**：单日隐藏日期筛选，日报/周报正文改轻卡片，灵卵进化路线改为已解锁形象 + 未解锁圆点。
- **快捷 / 仓库**：最近执行标签去描边；仓库移除按钮降为中性色并补充路径提示；统一中文标点。

## 修复

- 便签任务清单不再由 Markdown 正文和可勾选清单重复渲染。
- 复盘仅一天记录时不再出现无意义的「今天」筛选条。
- 问答中的文本 emoji 图标（管理模型配置、归类）换成与设计系统一致的 lucide 图标。

## 验证

- `npm run typecheck`、`npm test`（51 个离线脚本）、`npm run build` 通过。
- `npm run audit:features` 覆盖 11 个分区的渲染、溢出、按钮可访问性与输入框。
- `npm run audit:contrast`：硬失败 0。
- `npm run audit:ask`、`npm run audit:terminal`、`npm run audit:acceptance`、`npm run audit:screenshot` 全部通过。
- 安装版执行真实审批闭环：岛上点「允许」后 hook 收到 `behavior=allow`。
