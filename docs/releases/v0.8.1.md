# Agentic-Island v0.8.1

修复发布日暴露的入口问题，并保留 0.8.0 的全部能力。

## 修复

- **「循环」Tab 改为常显**：0.8.0 曾在未检测到 agent-autoloop 时隐藏该分区。发布主打功能不应因为可选依赖缺席而消失——现在任何安装都能看到入口；未装中台时分区内直接给出安装指引与一键复制安装命令。
- **编排入口显性化**：顶栏主按钮「可视化编排」直接进入四层自定义（全局 / 事件来源 / Agent / 通知通道 / 规则回路，另带 JSON 校对）。原来的「配置」更名为「连接」——它只管中台地址与本人密钥，并在连接卡内提供编排入口，避免被误解为全部配置。
- **编排工作台配色**：背景曾硬编码深色而文字跟随主题，浅色主题下变成「深底深字」几乎不可读；改为主题感知面板色（浅色=浅底深字，深色=深底浅字）。对比度审计新增 `loop:studio` 场景覆盖该浮层（此前完全漏测）。

## 接入提醒

本机中台（agent-autoloop）需要单独安装，它不在岛安装包里。装好后把 `agent-autoloop key new owner <名字>` 生成的本人密钥填进「循环 → 连接」即可拍板；地址留空会自动发现本机中台。

## 验证

- 类型检查、53 个离线测试、生产构建、12 分区像素级对比度审计（硬失败 0）、README 真实截图全部通过。
