# Agentic-Island v0.7.2

关键修复版：阻止升级流程删除本地加密密钥，避免配置在版本升级后无法解密；同时包含 0.7.1 的界面精修。

## 修复

- 0.7.0/0.7.1 的 Chromium 缓存清理误删了 `Local State`。它保存 safeStorage/OSCrypt 的 DPAPI 密钥；密钥重建后，旧 `config.json` 无法解密，应用会以空配置启动并把旧密文隔离为 `config.bad.json`。
- 现在只清理纯缓存（GPUCache、Dawn、Code Cache、Cache、Dictionaries 等），`Local State` 与 `Preferences` 永久保留。
- 新增 `scripts/test-cache-policy.ts` 回归测试，断言密钥与 Chromium 设置不在清理列表。
- 隔离出来的 `config.bad.json` 保持原样，便于在找回旧 `Local State` 后离线解密。

## 界面

- 十一个分区完成一轮精修：设置规则/门禁合并、问答候选与追问层级、待办工具带、资讯 TOP3 与流水线、复盘正文与灵卵路线、便签任务清单去重、快捷/仓库细节。

## 全功能自检

- `npm run typecheck`、`npm test`（含新增缓存策略测试）、`npm run build` 通过。
- 11 分区功能扫页、对比度审计（硬失败 0）、问答方法/气泡分析、终端 ConPTY、验收台补验证闭环、截图工坊批量导出、真实录屏导出全部通过。
- 安装版审批闭环：岛上点「允许」后 hook 收到 `behavior=allow`。
