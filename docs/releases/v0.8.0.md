# Agentic-Island v0.8.0

新增「循环」分区（Super-Agent）：把后台自主运行的 Agent 循环纳入灵动岛的统一监控、拍板与编排。首个支持方是 [agent-autoloop](https://github.com/KKKKhazix/agent-autoloop)——本机常驻、不开端口、任意命令行 Agent（Claude Code、Codex、DeepSeek Harness、自定义 command…）都能被它调度。岛的定位从「前台会话监控 + 审批」扩展为「前台 + 后台」双面拍板台。

## 流水线可视化

- **七阶段系统管道**：来源 → 规则 → 排队 → 执行 → 回执 → 拍板 → 复查；计数来自中台 totals，流光速度随活跃轮次变化，空闲完全静止。
- **规则拓扑**：每条规则一行——真实触发方式（定时/事件来源）、执行它的 Agent、名下并行的轮次 / 待拍板卡片 / 约定复查。多个事件同时进来时，能看到分流到各自规则。
- **动画由真实事实驱动**：SSE 事实带 type 与 rule/lane/source，哪条事实作用在哪条规则，就闪哪一行、光从上一阶段流到它命中的阶段；不是写死的循环动画。
- 性能红线：动画只用合成层属性，岛收起即全部停止。

## 可视化编排（完全态设置）

- 事件来源 / 规则回路 / Agent / 通知通道 / 全局（时区、askFirst、默认通道）全部表单化，带 JSON 校对视图。
- 草稿用官方 `agent-autoloop check` 校验通过才保存；保存自动备份原文件、原子替换，中台几秒热载。
- 来源/Agent/通道**编号改名自动同步全部引用**（when.source、emits.source、to、channels、defaultChannels、elsewhere）；规则一键克隆；rules.json 缺失可一键创建模板（拒绝覆盖）；未保存改动关闭/重载二次确认。

## 拍板与管理

- 待拍板卡片：选项/推荐/自由回答；挂起 30 分钟琥珀升级；**通道投递失败在卡片上直接告警**（含已放弃状态）。
- 数字键 1-9 快捷选择第一张卡的选项（对标 Agents 的 Y/N）。
- 进行中轮次：Agent 名、重试等待时刻（为什么不动）、停止中状态、会话深链（http 直开 / claude:// 等协议只复制）。
- 规则：暂停/恢复/立即运行/补跑暂停期间跳过的事件（花钱与外发动作两步确认）；规则行显示今日 tally 统计。
- 近况：今日与近 7 天用量（未上报轮数如实单列）、复查倒计时、被跳过事件列表、别处定时任务、每轮 why 来龙去脉、历史分页（按 nextBefore 往前翻）。
- 新 ask 卡与 Claude Code/Codex 命令审批**同权重**：置顶弹岛（不抢焦点）+ 响铃 + 迷你条深链；完成轮次自动进复盘活动流水。
- 系统问题横幅：规则文件写错 / 接单程序或通道离线 / 卡片投递失败聚合提示，无问题不占空间。

## 实时与接入

- SSE 增量流 `/v1/stream`：变更秒级到达，断线指数退避重连、按 seq 续读不重放；流在线时轮询退为兜底（间隔 5–60s 可选），连接胶囊显示「实时」徽标。
- 接入零门槛：本机装好 agent-autoloop 后地址留空自动发现；`agent-autoloop key new owner island` 生成密钥填入即可拍板；无密钥降级只读监控；远程中台填局域网地址。
- 归一化协议经真机验证（字段以实现为准），规模适配（分页/环形队列/推送 250ms 合并节流），多中台连接状态与多机 worker 归属可见。

## 安全

- 卡片文本按纯文本渲染（外部事件是不可信输入）；链接仅显式点击打开（主进程只放行 http/https，自定义协议只提供复制）。
- 自由回答只经 HTTP JSON 体回传，绝不拼接进命令行；密钥随 config.json 整体 DPAPI 加密。
- 编排只改本机 rules.json；保存前官方校验、失败不落盘、成功即备份。板块未启用时零轮询零请求。
