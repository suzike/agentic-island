# Agentic-Island v0.8.5

修复长时间运行后的整机鼠标卡顿：透明置顶窗口里仍有若干逐帧重绘的动画，收起面板也没有真正停止重绘。

## 修复

- **收起态真正停手**：面板收起此前只是 `translateY(-101%) + opacity:0`，CSS 动画与 `backdrop-filter` 仍在逐帧跑。现在收起时挂 `island-paused` 暂停面板内全部关键帧动画（含伪元素），并关闭背景模糊；展开时恢复。
- **迷你条动画改合成层**：隔离实例实测，开启动画时常驻迷你条把 GPU 进程推到 153% 核。
  - 网格位移：`background-position` → `transform`
  - 呼吸轨：去掉 `filter: saturate`，只动 `opacity`
  - 霓虹：去掉逐帧 `drop-shadow`，改静态阴影 + `opacity`
  - 宠物散步：`left`（每帧布局）→ `transform`
- **注意力动画**：`ui-sonar`（Tab 待处理点）、`ui-attention`（审批卡光晕）与迷你条状态脉冲由 `box-shadow` 动画改为「静态阴影 + 只动 transform/opacity」的伪元素，避免每次脉冲重绘整个图层。
- **鼠标移动热路径**：全屏透明窗口会转发高频 `mousemove`，此前逐条执行 `elementFromPoint`。现在合并到下一帧；收起态指针离开顶部 64px 时直接短路。
- **剪贴板轮询**：图片先算四角+中心的小块指纹，未变化时不再每 1.5 秒重新 resize + PNG 编码（剪贴板里放大截图时会长期占住主进程）。
