# Agentic-Island v0.6.18

发布日期：2026-09-15

这一版把上两版"已知边界"里点名欠着的账收掉：截图工坊对标清单的**最后四项**，以及录屏里"录制期有效果、切到导出期重建就没了"的**光标光晕与按键角标**。

## 截图工坊：最后四项

### 本地离线 OCR

走 **Windows 自带 OCR 引擎**（`Windows.Media.Ocr`，WinRT）：**不出网、不新增依赖、不下载模型**。本机实测引擎语言 `zh-Hans-CN`，识别一张测试图返回 `ZCode offline OCR 2026` 完全正确。入口在 AI 页，失败时如实报错并提示"云端视觉动作仍可用"。

实现上唯一麻烦的是 WinRT 的异步 API 在 PowerShell 里没有 await，得用 `AsTask` 桥接再 `Wait`。**这里踩的坑值得记下来**：PowerShell 双引号里的反引号是转义符，`"IAsyncOperation`1"` 会被吃成 `IAsyncOperation1`，于是筛选不到任何方法、报"无法对 Null 数组进行索引"——那个类型名必须用**单引号**包。同时给失败信息加上脚本原始输出，否则只会看到"没有返回结果"，无从查起。

### 文字卡片

把一段文字或代码直接渲染成美化卡片（复用现有的边框/背景/水印管线），生成后照常可以加标注、导出。排版（折行、超长单词硬切、行数上限、画布尺寸）是纯逻辑，有 8 项离线断言：按空白折行、**超长单词按字符切且绝不溢出画布**、空行保留、超限时如实标记截断。

### 标尺/参考线

预览上叠加像素刻度与虚线中线，只用于量尺寸、**不进成片**。刻度步长吸附到 1/2/5/10 这类可读值，不会出现"每 7px 一条线"这种没法读的刻度。

### 批量美化

多选图片（一次最多 50 张、单张 ≤160MB），把当前的边框/背景/水印套到每一张上，逐张**免对话框**存入「图片/Agentic-Island」，完成后报成功/失败张数。

## 录屏：导出期的光标光晕与按键角标

这两项此前只有录制期版本，在"拍摄与后期分离"之后切到导出期重建就消失了。

### 光标光晕

可选一枚"又大又软的软光斑"按成片帧序跟着光标走。光斑由渲染层用径向渐变现画成 PNG，主进程落盘成临时文件后作为**第二路输入**与画面 `overlay` 叠加。

**只重建"大而软"的光斑**：录制期那种细光环要求逐帧精确跟踪，FFmpeg 表达式做不到，所以导出侧不重建细光环。

顺手撞出一处反直觉事实：`overlay` 的表达式里**只有 `t`、没有 `in`**，而 `zoompan` 恰好相反（只有帧序 `in`、没有 `t`，写 `t` 会报 `Undefined constant`）。同一套折线航点编译器因此要按目标滤镜编译出两种时间轴。另外**带光晕的导出不能走 `-c:v copy` 直通**（要重新叠图），导出分流已把它归入"必须重编码"。

### 按键角标

录制期采到的**快捷键/导航键**（`Ctrl+S`、`Enter` 这类）在成片对应时刻、光标所在位置打一枚角标，约 900ms 后消失，最多 40 枚。

位置**直接用像素常数**而不是 drawtext 表达式：表达式里带 `max/min` 与逗号极易踩引号/转义的坑（实测报 `Failed to parse expression`），而每枚角标的位置本来就是常数、不需要表达式。

**隐私边界不变**：只采方向键/Enter/Tab/Esc 这类导航键与修饰键组合，**可打印字符一个都不采**，所以角标在任何情况下都不可能包含用户打出的文字；应用里也照实写明"这次录制没有采到快捷键"与为什么。

## 修复

- **截图工坊工具栏溢出**：新增动作按钮后头部是 `nowrap`，右侧按钮被挤出面板（截图里「重截」被切掉、标题与左栏叠字）。改为允许换行，全部按钮可见。
- **对比度审计的门禁抖动**：同一构建连续跑会出现 0 / 3 / 4 条"硬失败"，全部集中在 9–10px 的小字号（时间戳、"更多"这类元信息）。根因是测量方法——这种字号的笔画只有 1–2 像素宽，取到的"极值像素"多半仍是抗锯齿混色（实测颜色就是 50% 白），够不够接近纯色取决于亚像素定位。现在这类样本**不再计入硬门禁**，但仍单独列出供人复核并写明原因；门禁在三次连跑中稳定为 0 条。
- **录屏审计脚本把视频轨探错**：`audit:recording` 探测视频轨时**假定视频是 `#0:0`**（MP4 按首包时间排流序，原始采集的文件里音频完全可能排在前）；我把它改成带 `.*$` 的通配写法时又漏了 `m` 标志——JS 里不带 `m` 的 `$` 只匹配**整个输入的末尾**，于是只有最后一行的 `Video:` 能被命中，中间那行永远匹配不到，断言失败看起来像产品坏了。现在改成按行扫描找含 `Video: ` 的那一行，既不依赖流序、也不依赖 `$`。

## 验证

typecheck 与两套 tsconfig、**42 个离线测试**、生产构建、对比度审计（硬失败 0，小字号复核 0）、`audit:ask`、`audit:terminal`、`audit:recording`（真录合成与原始两段 + 真实点击注入 + 导出与成品自检，实测导出提示 `自检通过（9.1s · 30fps · H264 · 画幅按铺满重组）`）、NSIS 打包与 `verify:package`。

光晕与角标都有**像素级端到端断言**：同位置开/关对比取差、远端区域必须不变，避免"看起来生效了"其实什么都没画。

## 已知边界

截图工坊的**批量美化**入口仍在应用内，其原生多选文件框无法在隔离审计里自动化，需要人工点一次确认；录屏侧的键盘事件仍只覆盖快捷键/导航键（可打印字符永不采集），光标美化仍只支持软光斑。
