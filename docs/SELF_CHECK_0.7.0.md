没有把“静态存在”当成“功能和体验都通过”。下面的覆盖矩阵区分了：自动化实测、单元/契约测试、仅静态检查、未覆盖。

## 自检发现并修复

1. **复盘页出现 `undefined`**  
   历史活动缺少项目字段时，洞察文案输出“主战场是 undefined”。已把空项目归为“未归属”，并保留纯统计语义。

2. **设置页横向溢出 9–22px**  
   `Input` 外层 `width:100%` 与内边距在缺少全局 `border-box` 时把容器撑宽。已给共享 `Input` 增加 `boxSizing:border-box`；设置页巡检从 5 处溢出降为 0。

3. **设置页 16 个开关没有可访问名称**  
   `Switch` 之前只是无名称的 `<button>`。已改为 `role="switch"` + `aria-checked` + `aria-label`，并给设置页的验证门禁、审批策略、通用/自动化、迷你条和 CLI 接入开关补了具体标签。

4. **验收审计断言过期（不是产品回退）**  
   设置页文案从“全局补充规则”调整为“补充规则 / 验收规则与门禁”，审计等待条件已同步；改后验收台端到端审计恢复通过。

5. **仓库慢网加载没有边界**  
   GitHub 请求原来走裸 `net.fetch`，没有超时/取消。已改为统一 `netFetch`（12 秒超时）、可取消请求、骨架屏、慢网提示、取消等待和错误重试。

6. **新录屏能力缺成品级审计**  
   录屏审计已扩展为真实开启“多画面叠加 + 跟踪遮罩”录 6 秒，校验 manifest/MP4/落盘状态；再清理设置回到单源合成/原始对照，避免只测默认路径。

## 体验判断

### 通过

- 468px 窄面板下 11 个分区无横向溢出、无按钮裁切、无关键内容缺失。
- 空态文案能说明“为什么空”和“下一步做什么”。
- 资讯详情点击后 1.7s 内面板保持可见，旧的自动收起问题未复现。
- 命令面板 `Ctrl+K` 可打开；录屏工坊、截图工坊命令存在。
- 设置页开关现在对读屏软件有明确名称和开关状态。
- 录屏/截图成品仍以读回元数据和真实像素为准，不以“命令退出 0”代替成品校验。

### 仍需改进

- **AI 动作未做真实模型回归**：待办拆解、排期、站会、资讯综合、复盘生成等依赖用户模型配置，本轮只验证入口与纯逻辑。
- **OBS 虚拟摄像头仍依赖本机 OBS 与驱动**：代码集成与真实启停已验证，但无法替代用户机器上的 OBS 安装/驱动注册。
- **宠物/迷你条仍是状态型 UI**：入口和渲染未做长时间轮播/交互稳定性回归。
- **低对比度复核**：硬失败为 0，但仍有 63 条 3.0–4.5 样本，多为 9–10px 弱化文字；是否继续提高由视觉取舍决定。
