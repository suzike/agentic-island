# 录屏、截图与轻量剪辑对标

对标对象与资料来源：

- **BaoCut**：<https://baocut.com/zh-hans/>（本地优先、时间线、转写/字幕、AI 辅助剪辑）
- **OBS Studio**：<https://obsproject.com/>（场景/来源模型、编码器、性能统计、热键）
- **Cap**：<https://cap.so/> / <https://github.com/CapSoftware/Cap>（极简采集、点击聚焦、字幕、分享）
- **ShareX**：<https://getsharex.com/> / <https://github.com/ShareX/ShareX>（截图工作流、历史、标注、OCR、后处理）
- **Flameshot**：<https://flameshot.org/>（截图标注与快捷编辑）
- **Screenity / LosslessCut**：浏览器录制与无损剪切参考

## 本轮实际落地

1. **截图历史**：每一次框选、整屏、滚动长截图都自动归档到 `userData/screenshot-history`；工坊顶部可回看最近 40 张缩略图，点击载入原图，保留最近 120 张。它不占用「图片/Agentic-Island」导出目录，避免用户清理导出文件时把历史一起删掉。
2. **采集真实帧率**：录制条每 1.2 秒读取 `MediaStreamTrack.getStats()`，显示实际 FPS、丢帧率、实际像素尺寸与编码器。目标 30fps 不再被当成实际 30fps；低于目标 80% 会明确提示改原始画面或降低帧率。
3. **点击强调**：导出期按点击事件在点击后 1.2 秒内推近，解决“光标不动但用户刚点了关键按钮”时镜头没有重点的问题；可单独关闭。
4. **双语字幕**：真实转写后可按 40 条分块翻译，译文与原文写进同一条字幕，导出双语 SRT/VTT；不会生成两条同时间码字幕互相覆盖。
5. **导出交付面板**：成品落盘后显示读回自检结论、完整路径，并提供打开文件夹、复制路径、复制“标题/时长/章节”分享文案。
6. **过期会话回收**：Codex 关闭窗口不会补 `SessionEnd`；等待态超过 10 分钟自动从 Agents 移除，运行态给 60 分钟避免误删长构建。审批中的请求永远保留。

## 仍然明确没做的

- **OBS 式场景/来源模型**：多场景切换、每来源独立音频滤镜、虚拟摄像头。
- **Cap 式云分享链接**：需要对象存储与分享后端，本轮不伪造“已支持”。
- **动态区域遮罩**：按时间跟踪并对指定区域持续打码，需要逐帧跟踪与导出滤镜链。
- **ShareX 式上传目标/脚本流水线**：当前只有本地交付，不接第三方图床。

这些缺口保留在矩阵里，后续按“能真实验证”为准逐项补，不用文档代替实现。

## 验证边界

- 截图原生尺寸：隔离审计显示器 `1707×1067 @1.5x`，媒体流抓帧 `2560×1600`；快存后读回真实宽高。
- 录屏：同一活动画面 raw 采集高于画布合成；导出成品读回分辨率/帧率/编码并自检。
- 本轮新增的截图历史、采集统计、点击强调、双语字幕均有离线测试或类型/构建门禁；最终以安装版实机回归为准。
